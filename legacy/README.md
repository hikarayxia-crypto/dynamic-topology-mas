# 历史原型说明

本目录保存项目早期概念原型，仅用于追溯设计思路，不属于正式源码，也不应被
环境、训练脚本或测试导入。

## `topology_prototype_invalid.txt`

该文件原名为 `import numpy as np.txt`，包含智能体状态、简单邻接表、邻域均值
编码和三节点演示的混合原型。它不能直接运行，已知问题包括：

- 残留 `[span_x]` 标记会导致 Python 语法错误；
- NumPy 数组被用作 dataclass 可变默认值；
- 拓扑、神经网络编码和演示代码耦合在同一文件；
- 依赖 PyTorch，但原项目没有依赖清单或可用运行环境；
- 动态拓扑能力已经由 `core/topology.py` 中的 `DynamicTopology` 正式替代。

后续如需复用其中的状态编码思路，应在对应正式模块中重新实现并编写测试，
不要直接复制、改名为 `.py` 或作为运行入口使用。
